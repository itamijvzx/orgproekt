## Этап 2: оценка комплектов, сравнения и реального retrieval

`backend/tests/test_analysis.py` добавляет 12 тестовых случаев (включая четыре фазы parametrized ACL-теста). Полный финальный набор: **58 passed / 52.76 s**. Используются реальная PostgreSQL/pgvector, закреплённая локальная ONNX-модель и русские тексты; синтетического runtime embedding fallback нет.

| Проверяемое свойство | Доказательство |
|---|---|
| Фиксация входов, новая редакция не меняет комплект/результат | frozen_corpora_comparison_review_persistence_and_scope: третья редакция, digest и прежние ответы совпадают |
| Точные цитаты и обратимое представление diff | Source.quote == block[start:end]; сборка before/after из diff даёт точные строки |
| Решения человека отдельны от алгоритма | Два review с автором/версией; повтор идемпотентен, конкуренция 409; HR получает 403 |
| Нет доступа к чужим и смешанным комплектам | 404 прямых GET/POST, пустые списки, закрытая цитата не выдаётся; отзыв одной области скрывает весь запуск |
| ACL до ранжирования и повторная проверка после inference | Чужие anchor IDs отсутствуют в выдаче/счётчиках; изменение роли во время запроса приводит к 404 |
| Отзыв и отмена не оставляют поздний индекс | before/during/grant/cancel: SearchChunk/IndexReceipt не записаны |
| Сбой аудита атомарен | Нет ComparisonFinding/индекса после ошибки analysis.ready; dispatcher восстанавливает зависшее задание |
| Нельзя смешать поколения | index_version_changed; прежние векторы и результаты остаются |
| Нет молчаливого усечения | Длинный русский текст покрыт точными перекрывающимися диапазонами; векторы 384 и L2≈1 |
| Семантика не объявляется фактом | Категории совпадения/переноса/повтора/split/merge/отрицания/недостаточности; без цитаты «после» нет выдуманного пункта |

Golden retrieval: восемь разных функций (регистрация корреспонденции, восстановление систем, зарплата, кадровое оформление, юридическая экспертиза, бюджет, доступ, архив), по одному русскому запросу-перефразированию. Кorpus ограничен этими восемью anchors через настоящий API. Все релевантные anchors получили rank 1: Recall@3=1.0, MRR@3=1.0. Отдельный прогон `pytest -q -s tests/test_analysis.py` показал p95=0.030 s для восьми тёплых запросов TestClient. CPU cold load+encode двух строк: 1.02 s, RSS peak 476.8 МиБ. Эти числа не описывают сеть, большой корпус, конкуренцию API/двух worker или юридическую правильность выводов; следующий этап оценки должен расширить разметку и включить реальные предметные неоднозначности.

Playwright завершил полный сквозной сценарий за 42.3 s (43.5 s весь запуск), включая реальную очередь сравнения, русский diff, авторское рассмотрение, reload и поиск. Снимки: `11-corpora-1440.png`, `12-comparison-1440.png`, `12-comparison-390.png`, `13-review-history.png`, `14-hybrid-search-1440.png`, `14-hybrid-search-390.png`. UI-доказательства получены на отдельной disposable базе, не на рабочих аккаунтах. Основной стенд обновлён отдельно; READ ONLY сравнение подтвердило 314 прежних строк без изменений/потерь, аудит валиден, индекс покрывает 45 прежних документов. Это контроль сохранности обновления, не испытание восстановления из backup.

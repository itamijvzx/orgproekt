Автор: Синельников Иван Евгеньевич. Учебный портфолио-проект, существенно разработанный с помощью ИИ. Не является внедрением в реальную компанию или заменой профессионального аудита.

Полный источник требований — неизменённый `MASTER_PROMPT_ORGPROEKT.txt` (28.10.2026, прочитан полностью). Этот документ консолидирует решения; более поздние явные указания владельца уточняют мастер-промпт. Уточнение 09.11.2026: для новой локальной учебной установки MFA отключена через отдельный режим, автоматические резервные копии включаются по желанию. Существующая установка и права сохраняются; подробности — [LOCAL_DEMO.md](LOCAL_DEMO.md).

## Назначение и границы

Документальное сопоставление структуры, функций, назначений и версий организационных изменений. Факты имеют основание, период действия и время регистрации. Аудитор исследует и рекомендует; руководство принимает решения; HR регистрирует официальное исполнение. Нет автоматической оценки полезности людей, увольнения ИИ или вывода о нагрузке из числа функций.

Учебная версия **v0.1.0** включает локальный Windows/Docker, реестр организации, таблицы и схему, личный вход, серверные сессии и права отделов, кадровые события, историю и уведомления. Реализованы загрузка DOCX/PDF с редакциями и точными источниками, комплекты «до/после», сравнение и локальный гибридный поиск, предложения с обсуждением/согласованием/учётом исполнения, неизменяемые отчёты PDF/DOCX, приглашения и управление доступом. Зашифрованное резервирование и проверка восстановления в отдельную копию доступны по желанию.

Это ограниченный учебный выпуск, а не выполнение всего мастер-промпта. Gemini имеет выключенный адаптер; полноценный управляемый процесс LangGraph и производственная инфраструктура не завершены. Состав и ограничения — [RELEASE_0.1.0.md](RELEASE_0.1.0.md), история работ — [PROGRESS.md](PROGRESS.md).

## Основной сценарий

1. Аудитор входит по личному паролю; в режиме с MFA дополнительно подтверждает вход. Выбирает дату и отдел, читает таблицы, карточки и документальные основания.
2. Загружает вымышленные DOCX/PDF, фиксирует точные редакции в комплектах «до/после», сравнивает их по указанным критериям и проверяет обе цитаты. Автоматические кандидаты требуют рассмотрения человеком.
3. Сохраняет версию предложения с источниками, явно приглашает участников. Представитель отдела отвечает, независимый руководитель принимает решение, HR документирует исполнение, аудитор отдельно его проверяет.
4. Автор готовит отчёт по снимку предложения. Независимый рецензент проверяет редакцию и выпускает неизменяемые PDF/DOCX. Последующее исполнение не переписывает выпуск.
5. Кадровые назначения и прекращения регистрируются отдельными официальными событиями с датой и основанием. Отсутствие исполнителя отличается от вакансии, упразднения и неполноты данных; прежние факты и интервалы сохраняются.
6. Представитель финансов видит только разрешённый отдел, включая граф, списки, источники и уведомления. Прикладной администратор управляет доступом, не получая бизнес-данные. Отзыв прав проверяется сервером, в том числе при выдаче файлов и выполнении фоновой задачи.

## Неизменяемые принципы

Пустой поиск не доказывает отсутствие функции. Сходство текста не доказывает дублирование. Утверждение проекта не равно исполнению. Ответ не равен согласию. Согласие отдела не подменяет вывод аудитора. Изменение версии не наследует согласования. Облачный ИИ разрешается только для явно разрешённых синтетических материалов; ключ хранится исключительно на backend.

## Архитектура

React/TypeScript → Caddy (единый origin) → FastAPI → PostgreSQL/pgvector. Доменная транзакция одновременно сохраняет изменение, AuditEvent и OutboxRecord. Диспетчер → долговечная RabbitMQ → Celery worker → адресное уведомление. Модульный монолит, не микросервисы. Бизнес-данные не хранятся в localStorage. Zustand хранит только состояние представления в памяти.

Основной путь знакомства — Windows 11 и Docker Desktop, только loopback и вымышленные данные. Новая учебная установка использует HTTP; отдельная HTTPS-копия с ключами доступа необязательна. CI работает на Ubuntu 24.04, но это не проверка переноса действующей установки в отдельную Ubuntu VM. Production заблокирован конфигурацией: нужны проверяемый TLS компонентов, эксплуатационные процедуры и приёмка целевого размещения.

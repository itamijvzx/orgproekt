# Решения архитектуры

| Решение | Причина и ограничение |
|---|---|
| FastAPI + SQLAlchemy, один доменный backend | Прямое требование, понятный модульный монолит; worker использует те же доменные правила |
| PostgreSQL, UUID, календарные интервалы `[start,end)` | В день end назначение уже не действует. Exclusion constraint предотвращает пересечения одной штатной единицы даже при конкуренции |
| Оpaque cookie + серверная сессия | Немедленный отзыв без JWT, HttpOnly/SameSite, точный Origin и CSRF; Secure только при HTTPS |
| TOTP + 8 случайных резервных кодов | Бесплатный второй фактор; секрет шифруется Fernet отдельным ключом, коды хранятся SHA-256 как высокоэнтропийные случайные значения |
| RBAC + явный scope отдела | Название роли не даёт глобального доступа; нет null-scope wildcard. ACL кейса/поля расширяется только вместе с соответствующими модулями |
| Immutable official events + snapshots before/after | Исправление добавляет новое событие, текущая проекция назначения обновляется; история не переписывается |
| Transactional outbox и at-least-once | Commit изменения, аудита и outbox атомарен. Worker повторяет доставку безопасно благодаря уникальности уведомления |
| HMAC-цепочка аудита + append-only DB | Защищает от изменения журналов обычной ролью приложения; отдельная контрольная точка позволяет обнаружить усечение хвоста. Не защита от root хоста с ключами |
| Моноорганизация в срезе 0–1 | Организация «Северный контур» синтетическая. Мультиорганизационная изоляция пока не реализована; нельзя принимать реальные арендаторы |
| Ручная регистрация выдержки основания | Позволяет проверить доменный сценарий без выдуманного парсинга DOCX/PDF. Подлинность документа система не удостоверяет |
| Локальные профили agency-agents | Вспомогательные инструкции, не runtime-зависимость и не новые роли приложения |
| Оригиналы до 10 МиБ в PostgreSQL bytea | Атомарный commit файла/версии/audit/job, согласованная DB-backup. Рост базы контролировать до production; большие файлы требуют отдельного object storage протокола |
| Отдельный ограниченный процесс парсинга | Лимиты RAM/CPU/wall time и среда без секретов; парсер не исполняет инструкции и не запрашивает внешние отношения. Это не полноценная production-песочница |
| Неизменяемые блоки и диапазоны цитат | Источник открывается с точным выделением; PDF указывает страницу без выдуманных координат. Partial/OCR — явные состояния |
| DocumentJob с lease и текущими правами | Отмена/восстановление не допускают публикации устаревшего результата; учётная запись, сессия и scope проверяются до и после разбора |
| Gemini opt-in и отдельный smoke-check | Нет автозапросов при upload/наличии ключа, нет tools/fallback. Синтетический контекст и точные цитаты валидируются; полный LangGraph остаётся следующей частью |

Bootstrap среза выполняет владелец хоста командой seed только на пустой dev-базе. Пользователь access_admin не может самостоятельно присвоить бизнес-роль: интерфейс выдачи ролей пока не открыт. Production bootstrap и dual approval остаются отдельной задачей, а не обходятся публичной регистрацией.
